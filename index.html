Getting Started

SkillBridge is an AI-powered workforce intelligence platform built for Build For Bharat 2.0 by Code_Hustlers. It converts workforce data into actionable decisions through a Problem → Data → AI → Insight → Product → Impact pipeline.

1
Analyze a Resume

Go to Skill Analyzer, paste text, click "Analyze with AI" to extract and categorize skills.

2
Run Gap Analysis

In Gap Analysis, rate your current skills and calculate a weighted readiness score for any target role.

3
Generate a Roadmap

In Learning Roadmap, select your target role and current level for a 12-week upskilling plan.

4
Discover Internal Talent

In Talent Discovery, search for employees ready to transition into any target role.

🔬 Skill Analyzer

Extracts structured skills from free-form text using NLP and LLM-based techniques, then maps them to a canonical skill taxonomy.

Input formats: Resume text, Job Descriptions, LinkedIn profiles, skill summaries

Pipeline: Text → NLP/LLM → Skill Entities → Canonical Mapping → Skill Profile → Role Match Score

💡 Tip: Use "Quick load" buttons to see demo output instantly.

📊 Gap Analysis

Uses a weighted scoring formula to calculate how ready an employee is for a target role.

Gap Score = Σ [Skill Weight × (Required Level minus Current Level)] / Max Possible
Note: The readiness % is a model-derived indicator, not an objective qualification measure.

Gap categories:

  • Critical: Weighted gap > 60%
  • High: 40 to 60%
  • Medium: 20 to 40%
  • Low: < 20%

🗺 Learning Roadmap

Generates a personalized week-by-week upskilling plan based on: skill dependencies (learn PyTorch before MLOps), gap priority (critical gaps first), available time (hours/week), and market demand.

Each roadmap ends with a capstone project that covers multiple skill gaps in a single build exercise.

🔎 Talent Discovery

Analyzes your existing workforce to rank internal candidates for any target role. The system: loads employee skill profiles, computes semantic similarity to the required skill set, ranks candidates by readiness score, and shows individual gaps and upskilling effort.

Skill Trends

Analyzes historical job posting data to identify emerging and declining skill demand. Trends represent demand patterns : forecasts are demand indicators, not guaranteed employment outcomes.

❓ FAQ

What does the readiness % mean?
It is a model-derived indicator showing skill proximity to a target role. NOT an objective qualification measure : use it to guide development priorities.
How are skills extracted from resumes?
Using NER + LLM-based extraction, mapped to canonical skill taxonomy (O*NET + ESCO). Synonyms are normalized: "ML" → "Machine Learning".
Is this using live AI?
This HTML prototype simulates the AI pipeline with realistic sample data. The actual AI components (Sentence-BERT, NLP extraction, Gap scoring) are described in the Methodology section.
Who built this?
SkillBridge was built by Code_Hustlers for Build For Bharat 2.0, addressing the "Intelligent Talent and Workforce Ecosystem" problem statement.
How is this different from LinkedIn or other platforms?
SkillBridge focuses on INTERNAL talent redeployment, uses weighted skill-gap scoring (not keyword matching), generates dependency-aware learning roadmaps, and forecasts emerging skill demand : not just current job listings.
